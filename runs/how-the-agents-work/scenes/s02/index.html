In the first run, the fact-checker flagged two overstated lines, both genuine overgeneralizations.

Nothing it has not marked supported reaches the final voiceover.

The first measured voiceover ran 40 percent long, so real audio is now measured and trimmed before fact-checking.

Visuals are timed to the measured voice, and a broken scene is re-rendered alone.

The takeaway: small, checked hand-offs catch errors one agent would ship.
